# SLIP฿SUM

แอปรายรับ–รายจ่ายจากสลิปโอนเงิน (K PLUS / Krungthai NEXT) สไตล์อาร์เคดพิกเซล

- อ่านสลิปบนมือถือด้วย Tesseract.js — รูปสลิปไม่ถูกอัปโหลดไปที่ไหน
- ข้อมูลเก็บในเบราว์เซอร์ของเครื่องนี้เท่านั้น (สำรอง/นำเข้าเป็น CSV ได้)
- งบรายเดือน, หารค่าอาหาร, เงินคืนจากเพื่อน, กันสลิปซ้ำ

เปิดใช้: https://thanakorntp8.github.io/slipsum/
